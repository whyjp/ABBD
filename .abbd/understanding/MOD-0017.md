### Overview

`cmd/abbd/serve.go` is `abbd serve`: a small HTTP server on a loopback address that shows the human screen and turns each decision on it into an ordinary abbd CLI command run in the same process. The screen holds no gate logic of its own. Approving a card on the page and typing `abbd approve <KEY>` in a terminal run the same code, through `run` in `main.go`.

Most of the file is about making sure only the human, in the tab opened from the printed link, can send a decision. `serve` refuses any non-loopback `--addr`, draws a 24-byte random token, and prints `http://<addr>/#t=<token>`. The token sits in the URL fragment, which a browser never sends, so it lives only in this process, the terminal and the tab's `sessionStorage`. The address, never the token, goes to `serve.addr` in the session directory so the guard can deny an agent's requests to the screen. The file is removed when the server stops.

### Key Concepts

- **`screenServer`**: holds the `env`, the token, the bound address and `mu`, which runs one decision at a time and keeps page renders from reading the store mid-decision.
- **`ServeHTTP`**: serves only `GET /` and `POST /act`, and only when `Host` is the printed address. Any other name, as from DNS rebinding, gets 403.
- **`fromScreen` and `valid`**: a POST must carry `Origin: http://<authority>`, a `Sec-Fetch-Site` of `same-origin` when one is sent, and a form field `t` equal to the token under `subtle.ConstantTimeCompare`.
- **`actions`**: the table from the form's `do` value to an argv: `approve`, `reject` (with `--reason`), `confirm` and `confirm-reject` (with an optional `--value`), `align` and `realign` (both `align --confirm=<ids>`), and `couple`, which builds the key `from.kind.to` the same way `topology.Edge.String` spells an edge.
- **`keyed`**: puts the key on the command line as a positional argument and refuses one that starts with `-`, so a form cannot inject a flag.
- **`page`**: renders `screen.Build(env.screenInput())` with a fresh nonce and sends a Content-Security-Policy that allows only that nonce's script, plus `no-store`, `DENY` framing and `no-referrer`.
- **`act`**: runs the argv with `--root`, and answers with `abbd <argv>` and what the CLI printed. A CLI failure other than `exitNeedHuman` comes back as 422.

### Gotchas

- The page's script in `internal/screen/page.html` must match this file by hand: the `#t=` fragment and its hex pattern, the `/act` path, the `t` field and every `do` value.
- The answer goes only to the tab that sent the decision; it shows it once from `sessionStorage` after a reload, so a read-only viewer never sees it.
- Port 80 is dropped from `authority()`, because a browser leaves the default port out of `Host` and `Origin`.
