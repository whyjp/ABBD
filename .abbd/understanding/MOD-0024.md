### Overview

`internal/bootstrap` is the part of `abbd setup` that sits between the extraction script and the store. The script's JSON is the code-only truth: anchors, kinds, signatures. A document written by a reader (the pstack swarm's `supplement.json`) or rebuilt from old design notes (`adopt.json`) can only add to it. `Overlay(base, doc, src)` folds one such document onto the script result. It matches each document unit to a script unit, copies `purpose` and `responsibility` onto it as INFERRED or ADOPTED facts, sets `parent`, and appends the relations the script did not extract. Anchors and signatures always stay the script's.

`cmd/abbd/setup.go` calls `Overlay` once with `Supplement` and once with `Adopt`, then hands the result to `identity.Reconcile` with `ReplaceGuesses`. Finally it fills a `Report` and writes `Report.Markdown()` to `.abbd/bootstrap-report.md`, the file the human reads before aligning.

### Key Concepts

- **Source**: says which document an overlay comes from. `Supplement` is `Origin: model.Inferred, Strict: true`. `Adopt` is `model.Adopted` with `Names: true`, so it may rename units.
- **Strict**: a strict source was written by the same agent that wrote the script, so a unit that matches nothing means the script is incomplete. `Overlay` then returns the error "fix the script, or cite the code each one rests on" and setup aborts.
- **match**: picks the script unit of the same kind that shares the most anchors. A tie or no overlap at all is a gap, not a guess.
- **semantic unit**: a supplement unit that matches no script unit but carries `evidence` is admitted through `semantic()`, keyed `supplement#N`, with an unconfirmed INFERRED name and no signature or digest. These are the inside units and shared types only reading can find.
- **Findings**: `Matched`, `Conflicts` (claims the code contradicts, such as a different signature) and `Gaps` (one side lacks the other). For adopt, every relation the code does not show is a conflict queued for confirmation.
- **Report**: setup's Markdown summary. It holds no timestamps, so rerunning setup on unchanged code rewrites the same bytes.
- **Extracted wins**: an overlay relation identical to an extracted edge is dropped. One an earlier overlay already guessed gets this document's origin instead of a duplicate.

### Gotchas

- `Overlay` matches by anchor overlap, which is looser than `internal/identity`'s two-shared-anchors rule. A supplement unit needs only one anchor in common with its script unit.
- The report sentence "Three runs, the last with reseeded hash seeds" describes `deterministic()` in `cmd/abbd/setup.go`. Change one and the other must follow.
- `parent` is resolved only through document keys (`docTo`). A parent key that matched no unit is silently ignored.
