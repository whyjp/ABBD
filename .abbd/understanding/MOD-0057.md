## Overview

`internal/parts` proposes the responsibilities of one directory of code, so an extraction script can split a module whose own files hold most of its code into parts without a list kept by hand. `abbd parts DIR` lists the source files under the directory, test files left out, and hands them to `Propose`. A file directly inside the directory is a node of its own, and every file deeper down belongs to the node of the subdirectory that holds it. The package reads source text only, with no parser per language: a few regular expressions find top-level declarations, methods by their receiver type, import lines and the types a file constructs, implements or extends. The same input gives the same parts in any order, so a script that calls it stays deterministic.

## Key Concepts

- **Links** (`text.go`): `linksOf` finds, for each ordered pair of files, the names one takes from the other. A name counts when exactly one file declares it at its top level, the user does not declare it too, and it is not a member after a dot. A Go method or a Rust `impl` ties its file to the file that declares the type. An import line ties a file to another whose stem it names as a path or module segment. Comments and string literals are blanked first, keeping line numbers, so each link carries the first line that shows it.
- **Grouping** (`propose.go`): `Propose` joins nodes in a fixed order. Files whose stems share a first word are one family. A file only one group uses joins that group unless it is the larger of the two. Files that each construct, implement or extend one type another file declares are one family, named after that type. A small file no other file uses joins the group it takes the most names from. The single files three or more groups use, no larger than the median file, are the shared layer. A small file still alone joins the group that uses most of it. A subdirectory node is never folded into another group.
- **Names** (`describe`, `words`, `stripBrand`): a part is named by the type of its files that the rest of the directory uses most, or by its family's type, or by its largest node's stem. `words` splits a code name into lower-case words, so `HTTPSAdapter` is `https adapter`. A mixed-case first word that three or more types share, such as a project name, is left out.
