### Overview

`internal/screen` builds what the human sees: the latest turn's pending decisions first, then drift, trust, the confirm queue and a two-level map of the design. It reads the store and never writes the topology; every decision the page sends back goes to `abbd serve` and from there to the CLI. The same model feeds two outputs. `abbd serve` renders it live with forms and a script, and `publish` in `cmd/abbd/screen.go` writes the static `explorer.html`, `confirm-queue.html` and `graph.json` to `.abbd/generated/` through `Files`.

The flow is `Load` (store into `Input`), `Build` (`Input` into `Model`), then `Render` or `Files`. `Build` is deterministic: the same inputs give the same model, so the generated files only change when the data does.

### Key Concepts

- **`Input` and `Load`**: units, intended topology, turns, ADRs, runs, project config, the inputs hash, pstack how texts with each module's current digest, and the watermark read back from the existing `graph.json`.
- **`Watermark` and freshness**: the inputs hash and intended revision a generated file carries. `GeneratedFreshness` and `ActualFreshness` give `CURRENT`, `STALE` or `UNKNOWN`.
- **`Build` / `Model`**: runs `topology.Compare` and, for a live turn, `turn.Judge`, then fills `Pending` grade C `Card`s, `Drift` rows, align and queue groups, `Edges`, the `Overview` and one `Inside` per module.
- **`Badge`**: the trust a value has from its origin and confirmation: `stated`, `confirmed`, `inferred`, `adopted` or `extracted`. The word is the CSS class and the key into `labels`, the Korean wording in `page.go`.
- **Drawings**: `planOverview` lays out design units and approved relations only, so a guess or a turn never moves a box. `draw` adds wires by kind (`contract`, `bypass`, `semantic`, `new`, `realign`, `removed`) and `inside` draws a module's units. Both use `arrange` in `layout.go`.
- **`ask`**: puts a grade C item (contract changed, new relation, removed relation, unit removed) into words: title, why ABBD asks, what approve and reject do, and the safe default, with `diffSignature` for contracts.
- **`blocks` / `spans`**: split a how text into heading, list and paragraph blocks with `code` and **bold** spans, so the page never trusts markup in it.

### Gotchas

- Many strings must match across Go and `page.html`: wire kinds and CSS classes like `svg path.semantic`, badge words and `.pill.*`, the `"REALIGN"` effect the drift table tests, and the `#m-<ID>` link to each inside section.
- The `ask` wording describes what `abbd approve` and `abbd reject` do. Change what those commands do and the cards must change with them.
- `Files` blanks the working-tree fields, so generated files describe the `.abbd` inputs only and never claim the tree is current.
