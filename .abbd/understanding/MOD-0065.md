### Overview

`internal/store` is the only code that touches the `.abbd/` directory. A `Store` (from `Open`) roots every path at `<project>/.abbd` (`const Dir`) and puts session state in `<git-dir>/abbd/sessions` when the project is a git repository, so `git clean` or `checkout` cannot switch a session's mode off. Markdown with YAML frontmatter is the source of truth: units live in `architecture/` and `features/`, turns in `changes/CHG-*.md`, decisions in `decisions/ADR-*.md`, requirements in `requirements/`, module how-texts in `understanding/`. YAML files hold the rest: `intended.yaml`, `state.yaml`, `candidates.yaml`, `project.yaml` and `verification/runs/*.yaml`.

The store does persistence plus a few invariants that belong with the files. `readUnit` refuses a file whose name is not its ID or whose kind belongs in another directory. `SaveIntended` bumps `Revision` whenever the content changes. `NextID` records a per-kind high water so an ID is never reused. `SaveTurn` renders the turn's direct and far impact tiers against the graph as it is at save time.

### Key Concepts

- **`Store`**: a value holding the `.abbd` root and the sessions directory. Callers in `cmd/abbd` and `internal/screen` go through its methods and never build paths themselves.
- **Unit Markdown**: `renderUnit` writes frontmatter, a `# Name` heading and the anchor list. `readUnit` parses it and keeps everything from `## Notes` on as the user-owned `Notes`.
- **`writeFile`**: every write goes through it. It skips the write when the bytes are equal and otherwise writes a `.tmp` file and renames it, so a reader never sees half a file.
- **`State`**: the sync watermark in `state.yaml`: git revision, tree `Fingerprint`, `MDHash` of the unit files, and `HighWater` per kind.
- **`InputsHash`**: a hash of every file under `.abbd/` except `generated/` and the sessions directory. A generated page is STALE once it differs.
- **`ADR` and `Rejection`**: decision records. `Rejection` returns a question's standing rejection, the latest reject not overruled by a later approval.
- **Session state**: `SetMode` writes `<id>.on`, `AppendJournal` writes `<id>.journal`, and `ServeFile` is `serve.addr`, the running screen's address. Session IDs must match `^[A-Za-z0-9_-]{1,128}$`.
- **`Understanding` and `ModuleDigest`**: a module's INFERRED how-text, plus a 16-hex digest of every file its own and its children's anchors and evidence cite. A missing file still changes the digest.

### Gotchas

- The `"architecture"` and `"features"` names in `unitDirs` repeat `model.Kind.Dir`. Change both together.
- The guard in `cmd/abbd/guard.go` matches the literals `.abbd`, `extractor` and `.git/abbd`, not `store.Dir`. Moving the layout means editing the guard too.
- `Run.Output` is a slash path relative to `.abbd/` (`verification/runs/<id>.log`). `SaveRun` writes it there, and `internal/turn` prints it with the `.abbd/` prefix.
- The `.gitignore` for `sessions/` is written only when sessions live under `.abbd/`, which happens outside a git repository.
