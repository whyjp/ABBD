### Overview

`internal/evidence` decides whether the code still shows what a reader cited. A semantic unit, one the script never reported, and a semantic relation, a coupling a reader found, survive only on their `model.Evidence` quotes. This package checks each quote against the working tree, with no model or heuristics involved, so the same tree always gives the same verdict. It never discovers couplings. It only confirms or withdraws the ones a reader recorded.

`Checker.Apply` takes all units. For each present semantic unit it marks `Absent` when none of its quotes is found. For each semantic relation it sets `Dead`, a `Digest` and updated `Lines`. A live quote's `Lines` moves to where the quote is now, so edits above a quote never pile up into a false removal on a later run.

### Key Concepts

- **`Checker`**: holds the project root and a cache of loaded files, so each file is read once per pass. `New(root)` builds one.
- **Normal form**: `load` turns a file into `norm`, the file with all whitespace removed. For each byte it also keeps `line`, the line number, and `gap`, whether whitespace came before it. `normalize` does the same to the quote.
- **Matching rule (`Check`)**: the quote is searched in `norm`. It must start and end on word boundaries, so `charges` does not live on in `charges_archive`. When `Lines` is given, the match must overlap the cited range widened by `Slack` (3) lines. Without `Lines`, anywhere in the file counts.
- **`Result`**: `Live`, `At` (the line or range where the quote now sits), and `Digest`, 8 bytes of SHA-256 over those raw lines.
- **Digest**: lets a turn see an edit to the cited lines even while the quote itself survives. `all` joins the digests of every live item in order.
- **Live-while-any**: a fact stays live while any one of its evidence items is found.

### Gotchas

- `Slack = 3` is also written as prose in `plugins/abbd/skills/abbd-setup/SKILL.md` ("must start within three lines of `lines`"). Change both together.
- Because whitespace is ignored, a quote can match across line breaks and blank lines. `At` can then be a range wider than the quote looked.
- A missing file is just not found. It does not raise an error, so a renamed file quietly makes its units absent and its relations dead.
- Units and relations without evidence are never touched, so script-reported facts never go absent here.
