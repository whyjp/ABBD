## Overview

`cmd/abbd` is the ABBD command line. It is one `package main` that dispatches seventeen verbs over the `.abbd/` directory, where a repository keeps its architecture topology. Humans and assistants run it from a shell, and the block that `abbd install` writes into `CLAUDE.md` points assistants to the `/abbd` skill for how to use it. The usage text calls the CLI a lever. It registers the project's extraction script and proves it deterministic. It keeps unit IDs stable across runs and checks every quoted piece of evidence against the working tree. It records what readers infer and what humans state, refreshes and retracts those claims, and converts an old-format state once. It stores pstack how's module texts and answers `explain`, `path` and `impact` queries. It never judges, blocks, asks or records a decision. Even `diff --check` only exits 1 when a change reaches the boundary between modules, so a CI job can label the PR.

The package is glue. The logic lives in `internal/`. `model` holds the writers and the precedence table that picks which claim shows, `identity` reconciles IDs, `evidence` checks quotes, `topology` answers queries and diffs, `screen` renders, `store` owns the on-disk format, `gitx` reads git, `extract` parses the script's JSON, `bootstrap` folds in the supplement, and `group` adds directory groups when a view gets crowded. `cmd/abbd` parses argv against a declarative command table, decides which writer each record speaks for, wires those packages together in a fixed order, and prints results line by line. After every verb that writes, `run` calls `publish`, which re-renders `.abbd/blueprint/index.html` and then `graph.json`.

## Key Concepts

- **Command table** (`main.go`): the `commands` map. Each verb names its flags from `flagDefs`, its allowed positional counts, whether it takes `-- ARGV`, and whether it `writes`. `parse` joins the first two words to find verbs like `record unit`, and `parseInterspersed` accepts flags anywhere on the line. A usage error exits 64 and a failed verb exits 1.
- **Sync pipeline** (`main.go`): `syncActual` loads the stored units through `store.Writable`, which refuses an old-format state, then the candidates and the state. It snapshots the tree, reads git renames since the last fingerprint, and runs `identity.Reconcile`. It then runs `evidence.Checker.Apply` and `group.Fallback`, and saves units, candidates and state. It refuses an extraction with no units when units are already stored. After `sync` and `setup`, `attention` prints the drifted and dead evidence counts and each parent conflict.
- **Sync revision** (`main.go`): the revision a drifted item counts from. It stays `state.Revision` while the tree's fingerprint is unchanged, so committing `.abbd/` is no later revision, and becomes `gitx.Head` once the tree changes.
- **Writers** (`main.go`, `setup.go`): `sync` passes `identity.Sync`, so only the script's claims are replaced. `setup` passes `identity.Setup`, so the supplement's claims are replaced too and what `abbd record` wrote stays. A supplement unit that setup no longer reports stays when a human stated something about it, and setup prints it as `kept`.
- **Determinism proof** (`setup.go`): `deterministic` runs the script three times and demands identical output. The third run sets new `PYTHONHASHSEED` and `PERL_HASH_SEED` values. A mismatch reports the first differing line, and nothing is saved.
- **Record writer** (`record.go`): `writer` is `human` when `--source` is given and `reader` otherwise. Each writer's claim on an edge or a parent sits beside the others. `recordRelation` refuses an edge the script already claims and a reader's claim on an edge a human stated. `recordParent` refuses a directory group that sync made and a placement that makes a unit its own ancestor. A human's parent stores the script's parent as `over`. When a higher claim still wins, `recordParent` prints where the unit stays.
- **Live citation** (`record.go`): `citations` parses each `PATH:LINES:QUOTE`, normalizes it with `extract.NormalizeEvidence`, and refuses a quote the file it names does not hold now. A unit from `record unit` has a reader's name and stays present until its evidence is dead. Its `--parent` must be a present module or feature, and becomes the reader's parent claim on the unit's own evidence.
- **Refresh and retract** (`record.go`): `refresh` serves `record evidence` on a unit, `ID.parent` or an edge. It replaces the evidence of the reader's claim there. When only the supplement's claim is there, it adds a reader's claim above it, and a supplement unit becomes the reader's. A refreshed unit that is absent comes back unless it was retracted. `retract` removes the writer's own claim on the target and masks each lower INFERRED claim on it, bound to that claim's content. A run that can change nothing says the target is already retracted, or fails when the claim left is one it may not hide, such as the script's.
- **Migrate** (`migrate.go`): converts an old-format state once, with the supplement setup used (default `.abbd/extractor/supplement.json`) folded onto a fresh extraction. An INFERRED claim becomes the reader's when the supplement makes no claim on the same target. Every item but the script's that is not live now becomes dead with the reason `dead before migration`. It writes nothing when the present units, their parents, or the shown relations with their origins would change.
- **Query resolution** (`query.go`): `find` takes a unit ID, a name, a file, a directory, a symbol or a phrase through `topology.Find`. A match that is not exact prints the best five with reasons. `explain` lists every parent claim when a unit has more than one, and marks each drifted or dead item. `impact` also seeds every other unit anchored at a queried path.
- **Evidence and status** (`evidence.go`): `abbd evidence` checks the items of the claims that show and prints each as live, drifted or dead. It never writes, so a drifted item stays drifted. `abbd status` prints whether the state and the blueprint are current, the unit, relation and module-text counts, the drifted and dead items, every mask and every parent conflict.
- **Fingerprint** (`install.go`): a git tree object of the working tree minus `.abbd/`, saved in the state at sync. `status` reports STALE when it no longer matches the tree. `keepingCurrent` moves it along when `install` edits `CLAUDE.md` while the state is current.
- **Understanding** (`understand.go`): how's text for a top-level module, stored INFERRED with `store.ModuleDigest`. `understand` refuses to store the same text again on changed code, and `explainHow` shows it as CURRENT or STALE.
