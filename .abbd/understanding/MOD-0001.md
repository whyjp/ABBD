### Overview

`cmd/abbd` is the `abbd` binary. The /abbd-setup and /abbd-mode skills, the hooks in `plugins/abbd/hooks/hooks.json` and a human at a terminal all call it, and nothing else. It has little logic of its own. Each verb opens the `.abbd` store with `store.Open` and asks the internal packages (`identity`, `topology`, `turn`, `confirm`, `evidence`, `bootstrap`, `screen`) to decide. It writes the result back and prints lines for the skills to read. `guard.go` and `serve.go` are in this package too, but they are separate modules.

Every command goes through `run` in `main.go`. `parse` finds the verb in the `commands` table, trying two-word verbs such as `turn end` first. It builds a `flag.FlagSet` from `flagDefs`, so a command only gets the flags it lists. A command that changed the store's `InputsHash` republishes `.abbd/generated/`. Exit codes: `errNeedHuman` gives 2, any other error gives 1, a bad command line gives 64. `hook` always exits 0.

### Key Concepts

- **`commands` / `command`**: the verb table. An entry lists its flags, subcommands, positional counts, whether it accepts `-- ARGV` and whether it needs `--session`.
- **`env`**: the context of one invocation: options, stdio and `store.Store`. Every command is a method on it.
- **`errNeedHuman` (exit 2)**: the command did its part and a human decides next. The skills stop on it.
- **`syncActual` / `reextract`**: the only way into the actual topology. It runs the registered script, then `identity.Reconcile`, then `evidence.Apply`, and saves the units and the `State`.
- **`view` / `load`**: the units, the intended topology, the `phase` and the drift `items`. Almost every command starts here.
- **`deterministic`**: setup runs the script three times, the last time with `PYTHONHASHSEED` changed, and refuses it if the output differs.
- **Turn commands** (`turn.go`): `turnStart` fingerprints the tree and the extractor. `turnDeclare` grades changes A, B or C. `turnEnd` gates the turn and marks it `Synced`, `Closed`, `Draft` or `Blocked`.
- **`hooks` map** (`hook.go`): event name to handler. Hooks do nothing unless `ModeOn(session_id)`. `hookStop` blocks the stop of an OPEN turn that changed the tree, once.
- **`citations` / `understand`**: proposals must quote code that is in the working tree now. `understand` stamps how's text with `ModuleDigest`.

### Gotchas

- The skills match on output text such as `active: resuming`, `C QUESTION`, `UNEXPECTED` and `not deterministic`. No type enforces this text. Before changing a `Fprintf`, check `plugins/abbd/skills/*/SKILL.md`.
- The tool names in `hookPreToolUse` and the keys of `hooks` must match the matchers and event keys in `hooks.json`.
- `turnEnd` refuses to finish if anything under `.abbd/extractor/` changed during the turn.
- `approve` and `reject` act on the open turn when one exists, and on the intended topology otherwise.
