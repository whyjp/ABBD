## Overview

`cmd/abbd` is the command-line front end of ABBD. It is a single `package main` that dispatches about a dozen verbs. The verbs read and write the `.abbd/` directory, which holds the repository's architecture topology: modules, contracts and the relations between them. The usage text calls the CLI "a lever": it runs the project's registered extraction script, keeps unit IDs stable across runs, checks that every quoted piece of evidence is still in the working tree, records what readers infer and what humans state, and re-renders the blueprint page (`.abbd/blueprint/index.html` plus `graph.json`) after every write. By design it never judges or blocks anything. Even `diff --check` only returns an exit code that a CI job can turn into a PR label.

The package is thin. The real logic lives in `internal/` (`identity` for ID reconciliation, `evidence` for quote checking, `topology` for queries and diffs, `screen` for rendering, `store` for the on-disk format, `gitx` for git facts). `cmd/abbd` does four things: it parses the command line against a declarative command table, applies the CLI-level rules (what a valid record looks like, which origin wins, what to refuse), wires the internal packages together in the right order, and prints the results line by line.

## Key Concepts

- **Command table** (`commands` in `main.go`): each verb lists its allowed flags, how many positional arguments it takes, whether it accepts `-- ARGV`, and whether it `writes`. A writing verb triggers `publish()`, which re-renders the blueprint.
- **Origin**: every fact and relation carries one. `EXTRACTED` comes from the script, `INFERRED` comes from a reader with evidence, and `USER_STATED` comes from a human with a `--source`. When they collide, EXTRACTED beats USER_STATED, and USER_STATED beats INFERRED.
- **Evidence** (`PATH:LINES:QUOTE`): a verbatim excerpt of code. A finding enters the state only if its quote is live in the working tree now. A unit whose name is INFERRED (a "semantic" unit) stays present only while its evidence is live, and a relation that carries evidence goes `dead` once its quotes are gone.
- **Guesses mode**: `sync` runs `identity.KeepGuesses`, which keeps the stored INFERRED facts because the script cannot see them. `setup` runs `identity.ReplaceGuesses`, where the supplement owns the guesses and anything it no longer says is withdrawn unless a human stated something about it.
- **Fingerprint / state.yaml**: a git tree object of the working tree minus `.abbd/`, recorded at sync time. If it differs from the current tree, the state is STALE.
- **Understanding**: pstack how's Overview and Key Concepts text for a top-level module, stored with a digest of that module's code so it can be shown as CURRENT or STALE.
