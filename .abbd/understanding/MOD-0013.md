## Overview

`internal/evidence` decides, deterministically, whether the working tree still holds the code a reader cited. The extraction script cannot see some facts, such as a coupling through a convention or a unit nothing in the code declares. A pstack reader, or a person running `abbd record`, adds such a fact with a `model.Evidence`, which names a path, an optional line range and a verbatim quote. This package only finds that text again. It never judges whether the coupling is real and never writes a file. The same tree always gets the same answer.

The package is one file, `evidence.go`, with two entry points. `Checker.Check` tests one item. It looks first within the cited lines plus `Slack`, then takes the quote's only occurrence anywhere in the same file. When the file no longer holds the quote, a long enough quote may follow its code into exactly one other file under the owning unit's anchors. A quote found twice in that search is ambiguous and stays dead. `Checker.Apply` writes the verdicts into units. A present semantic unit whose evidence is all gone becomes `Absent`. A relation with evidence, none of it found, becomes `Dead`, and every checked relation gets a fresh `Digest`. A reader's INFERRED parent whose `ParentEvidence` is gone is cleared. Each live item's `Lines` and `Path` move to where the quote is now, so edits above it never add up to a false removal. `syncActual` in `cmd/abbd/main.go` runs `Apply` right after `identity.Reconcile`, and `abbd record relation` runs it on the one unit it changes. `abbd evidence` calls `Check` to print each quote as live or dead. `abbd record` calls `Check` with no anchors to refuse a quote its file does not hold now.

## Key Concepts

- **`Checker`** (`evidence.go`): a project root, a cache of each file loaded, and a sorted list of committable files built on first need from `gitx.WorkingFiles`. `New(root)` makes one per command, so it is a snapshot of the tree.
- **Normalized file** (`evidence.go`): the raw lines, plus `norm` (the text with all whitespace removed), `line` (the line of each byte of `norm`) and `gap` (whether whitespace stood before that byte). Reformatting never kills a quote.
- **Word boundary** (`evidence.go`): a quote that ends in a word character must end where the code's word ends, and the same holds at its start. So `charges` does not live on in `charges_archive`.
- **`Slack`** (`evidence.go`): 3 lines of tolerance around the cited range. A quote with no `Lines` is unbounded and takes its first occurrence in the file.
- **`MinMoveQuote`** (`evidence.go`): 24 non-whitespace characters. A shorter quote never leaves its file, since it could match unrelated code.
- **Move candidates** (`evidence.go`): files git would commit, with the cited file's extension, that `isTest` does not reject and `covered` places under an owner anchor. A test is a `_test.go`, `.test.` or `.spec.` file, or anything under `test`, `tests` or `__tests__`. Outside a repository the list is empty.
- **`Result`** (`evidence.go`): `Live`, `At` (where the quote was found, such as `4-5`), `Digest` (the first 8 bytes of a SHA-256 of the matched raw lines, in hex) and `Path` (set only when the quote moved to another file).
- **Fact verdict** (`evidence.go`): `all` keeps a fact live while any of its items is live. A relation's digest joins its live items' digests with commas, so a diff sees an edit to quoted lines even while the quote survives.
- **Semantic** (`model.go`): a unit is semantic when its name is INFERRED. A relation is semantic when it carries evidence, whatever its origin.
