Overview

internal/evidence decides, deterministically, whether the working tree still holds the code a reader cited. The extraction script cannot see some facts, such as a coupling through a convention or a unit nothing in the code declares. A pstack reader adds such a fact through the setup supplement or abbd record, with a model.Evidence that names a path, an optional line range and a verbatim quote. This package only finds that text again and gives the item a status: live, drifted or dead. It never judges whether the coupling is real and never writes a file. The same tree always gets the same answer.

The package is one file, evidence.go, and it imports only internal/model. An item's scope is the file it names, and a quote never follows into another file. Checker.Check tests one item. It takes the occurrence nearest the cited lines within Slack, so two places of one quote cited a line or two apart each keep their own, and otherwise the quote's only occurrence anywhere in the file. A quote found twice with neither near the cited lines is not found. Checker.Status turns that answer into the item's next status. Checker.Apply checks every item of every present unit: a semantic unit's own evidence, and the evidence of every parent claim, every relation claim, shown or hidden, and every phrase note. A present semantic unit whose evidence is all dead goes absent with the reason evidence-dead. Each relation claim with evidence gets a fresh Digest, and each live item that names lines moves them to where the quote is now, so edits above it never add up to a false removal. Apply ends with model.Resolve, so a dead claim stops showing and the next claim shows. syncActual in cmd/abbd/main.go runs Apply at the sync revision right after identity.Reconcile. save in cmd/abbd/record.go runs it with no revision on the one unit that record relation, record parent, record evidence or retract changes. abbd evidence calls Status with no revision to print each item of the claims that show. abbd record calls Check to refuse a quote its file does not hold now, and abbd migrate calls it to mark every item but the script's that is not live as dead. store.ModuleDigest calls Around to hash the lines near each quote of a file a module only quotes. abbd understand calls Occurrences to refuse a note's quote its file holds more than once, and store.NoteStamp calls it to mark a note's place missing once its quote is no longer unique.

Key Concepts

  • Checker (evidence.go): a project root and a cache of each file loaded, with nil for a file that is missing. New(root) makes one per command, so it is a snapshot of the tree.
  • Normalized file (evidence.go): the raw lines, plus norm (the text with all whitespace removed), line (the line of each byte of norm) and gap (whether whitespace stood before that byte). Reformatting never kills a quote.
  • Word boundary (evidence.go): a quote that ends in a word character must end where the code's word ends, and the same holds at its start. So charges does not live on in charges_archive.
  • Slack (evidence.go): 3 lines of tolerance around the cited range. Among the occurrences within it, the one nearest the range wins, and the earlier one on a tie. A quote with no Lines is unbounded and takes its first occurrence in the file.
  • Result (evidence.go): Live, Gone (the file does not exist), At (where the quote was found, such as 4-5) and Digest (the first 8 bytes of a SHA-256 of the matched raw lines, in hex).
  • Status rules (evidence.go): a found quote makes the item live and clears Since and Reason. A missing file makes it dead with the reason PATH is gone. A file without the quote makes it drifted, with Since set to the sync's revision. A sync at a later revision that still finds it drifted makes it dead with the reason drifted since REV and not refreshed. Status returns a dead item unchecked, so dead is terminal. With no revision, a drifted item stays drifted.
  • Script evidence (evidence.go): the script restates its quotes on every sync, so its items never drift. Apply checks them with drifts false. A quote the file does not hold makes such an item dead, and a dead one is checked again.
  • Claim status (evidence.go, claims.go): all checks a claim's items in order. model.StatusOf makes the claim live while any item is live, else drifted while any is drifted, else dead. A relation's digest joins its live items' digests with commas, so a diff sees an edit to quoted lines even while the quote survives.
  • Semantic (model.go): a unit is semantic when its name's writer is INFERRED, the supplement's or a reader's. A relation is semantic when it carries evidence, whatever its writer.
  • Around (evidence.go): the raw lines that hold a quote now, found as Check finds it, with n lines on each side, clamped to the file. It returns false when Check would not find the quote.
  • Occurrences (evidence.go): how many places the quote's file holds it now, whatever lines the item names, matched as Check matches. It is 0 for a missing file or an empty quote.
