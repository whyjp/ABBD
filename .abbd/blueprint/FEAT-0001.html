/abbd의 안 FEAT-0001

한 단계 위로 모듈과 계약으로

테두리의 칸은 이 모듈의 계약입니다. 채운 칸은 내놓는 계약, 빈 칸은 쓰는 계약이고, 맡은 단위에 가까운 변에 놓입니다. 점선 칸은 계약 없이 닿는 다른 모듈입니다.

제공(구현) 씀 의존 색: 상자마다 한 색이고, 선은 그 선이 나오는 상자의 색입니다. 여러 상자에서 모인 줄기는 회색입니다. 주황은 계약을 거치지 않는 직접 의존에만 씁니다. 선 끝의 모양이 종류를 말합니다 끊긴 선: 다른 선 아래로 지나감. 점은 만나는 곳 선 위의 낱말: 건너는 것(phrase), 없으면 관계가 생기는 방식(via) 옅은 점선: 거슬러 오르는 선(위로, 또는 같은 줄에서 왼쪽으로). 상자에 마우스를 올리면 그 상자의 선만 남습니다 판독: pstack 리더가 읽은 관계 확인: 사람이 말한 관계 표시 없는 선: 코드에서 추출 ×N 한곳으로 모이는 선 N개
선이 많아 한 상자씩 봅니다. 상자를 고르면 그 상자와 닿는 상자, 그 사이의 선만 그립니다: /abbd ground rules /abbd ask the blueprint before the code /abbd read the code through pstack /abbd record what a reader found /abbd what the human states /abbd after work /abbd evidence and CI gate

이 모듈의 설명은 아직 없습니다. abbd understand FEAT-0001 FILE로 채웁니다.

안의 단위

  • /abbd ground rules 기능
    Sets what the blueprint is, that the abbd lever never judges, that the skill sits under any mode, that setup must run first, and how to weigh a fact by its origin. 판독
    키와 앵커FEAT-0003 plugins/abbd/skills/abbd/SKILL.md
  • /abbd ask the blueprint before the code 기능
    Before work, opens the blueprint for the modules involved and answers the question through status, explain, path and impact queries. 판독
    키와 앵커FEAT-0004 plugins/abbd/skills/abbd/SKILL.md
  • /abbd read the code through pstack 기능
    When the topology is not enough, hands the code reading to pstack how, or blast-radius for a change across modules, starting from the units the queries named. 판독
    키와 앵커FEAT-0005 plugins/abbd/skills/abbd/SKILL.md
  • /abbd record what a reader found 기능
    Writes back couplings and units a reader found, with verbatim quotes, and refreshes a STALE module's how text. 판독
    키와 앵커FEAT-0006 plugins/abbd/skills/abbd/SKILL.md
  • /abbd what the human states 기능
    Records a purpose, responsibility or coupling the human states, with a source reference. 판독
    키와 앵커FEAT-0007 plugins/abbd/skills/abbd/SKILL.md
  • /abbd after work 기능
    Syncs the state to the changed code, reports the topology diff in plain words in the reply and the PR, and commits .abbd/ with the code. 판독
    키와 앵커FEAT-0008 plugins/abbd/skills/abbd/SKILL.md
  • /abbd evidence and CI gate 기능
    Describes the checking surface: which quotes still hold, and the diff --check exit code a CI job uses to label a PR. 판독
    키와 앵커FEAT-0009 plugins/abbd/skills/abbd/SKILL.md
