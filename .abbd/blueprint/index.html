ABBD

ABBD keeps a repository's architecture as a checked topology in .abbd/ and draws it as a blueprint, so a person can understand what an agent built and changed, and decide what to do about it. A deterministic script extracts the units and relations, readers add what code alone cannot show with quoted evidence, and every sync checks that evidence and marks what went stale.

주요 부분

  • abbd CLI 모듈 Owns the abbd command line: parsing argv against the command table, running each verb over the store, and rendering the blueprint after every verb that writes.
  • internal/bootstrap 모듈 Folds the supplement onto the extraction result: matches supplement units to script units by shared anchors, copies their purpose and responsibility as INFERRED, adds evidence-backed units the script cannot see, and adds the evidence-backed couplings the script did not extract.
  • internal/evidence 모듈 Finds each cited quote in its file whitespace-insensitively and on word boundaries within the named lines plus a three-line slack, marks semantic units absent and semantic relations dead when no quote survives, and moves live line numbers and digests to where the quote is now.
  • internal/extract 모듈 Decodes the extraction JSON with unknown fields refused, validates kinds, names, anchor paths, signatures, parents and relation kinds, and turns evidence into anchors so a reader's unit has a stable identity.
  • internal/gitx 모듈 Shells out to git for HEAD, files and blobs at a revision, the merge base with the default branch, a working-tree snapshot tree, and renames or changes between two snapshots.
  • internal/identity 모듈 Reconciles stored units with a fresh extraction purely: matches them by shared anchors, mints never-reused IDs, decides which facts and relations each origin keeps, and records merge candidates.
  • internal/model 모듈 Defines units, facts with origins, anchors, IDs, relations, evidence and edges, and validates them: why-fields are never EXTRACTED, a USER_STATED fact carries a source, only contracts carry a signature, and only known relation kinds join known unit kinds.
  • internal/screen 모듈 builds a deterministic two-level model from the stored units (an overview of top-level modules and contracts, one inside per module, and the unit catalogue), says whether the state and the blueprint are current, and renders index.html and graph.json with a watermark
  • internal/store 모듈 Owns the on-disk layout of .abbd: unit Markdown files, candidates, state, project config, module understandings and blueprint files, plus the fingerprints that tell when derived views are stale.
  • internal/topology 모듈 Answers read-only queries over stored units: one unit at a glance, the strongest shortest path between two units, what a change to some units reaches, and how the topology differs between two revisions.
  • internal/group 모듈
  • pstack (external) 모듈 The pstack plugin the ABBD skills hand reading and fan-out to; it lives outside this repository.

  • /abbd 기능 Tells the assistant to read the blueprint and ask explain, path and impact before work, record couplings, units and human-stated facts with their origin, and run sync and put the diff in the PR after work.
  • /abbd-setup 기능 Drives the one-time setup: a pstack swarm reads the code, a deterministic extraction script plus a supplement of readers' findings feed abbd setup, how's text is stored per module, and abbd install writes the CLAUDE.md block.
  • /abbd ground rules 기능 Sets what the blueprint is, that the abbd lever never judges, that the skill sits under any mode, that setup must run first, and how to weigh a fact by its origin.
  • /abbd ask the blueprint before the code 기능 Before work, opens the blueprint for the modules involved and answers the question through status, explain, path and impact queries.
  • /abbd record what a reader found 기능 Writes back couplings and units a reader found, with verbatim quotes, and refreshes a STALE module's how text.
  • /abbd what the human states 기능 Records a purpose, responsibility or coupling the human states, with a source reference.
  • /abbd after work 기능 Syncs the state to the changed code, reports the topology diff in plain words in the reply and the PR, and commits .abbd/ with the code.
  • /abbd evidence and CI gate 기능 Describes the checking surface: which quotes still hold, and the diff --check exit code a CI job uses to label a PR.
  • /abbd-setup find units with a reader swarm 기능 Lists unit candidates from the layout and fans the reading out to a pstack swarm of how-explorer workers that report in the extraction format.
  • /abbd-setup build the deterministic extractor 기능 Writes a deterministic script that prints the extraction JSON from the code alone, and reconciles it against the swarm result.
  • /abbd-setup write the reader supplement 기능 Writes supplement.json with what only reading tells: purposes, units and couplings the script cannot see, and the grouping into parts.
  • /abbd-setup run setup and resolve refusals 기능 Runs abbd setup with script and supplement, and says how to fix each refusal it can give.
  • /abbd-setup verify, install and hand over 기능 Checks the blueprint against the swarm's account, installs the CLAUDE.md block, commits, and hands ongoing work to the abbd skill.
  • /abbd-setup extraction format 기능 Defines the JSON contract shared by swarm workers, the extractor script and the supplement: unit kinds, relation kinds, via values, evidence and parent rules.
  • pstack /how 기능 pstack's subsystem walkthrough; ABBD uses it to read code and to write each module's text.
  • pstack /swarm 기능 pstack's parallel fan-out; ABBD setup reads the code and asks for the grouping through it.
  • abbd reader 기능 ABBD's own recipe for reading a module and storing what it found; it needs only the abbd CLI and uses pstack as an optional engine when installed.
  • /abbd-setup store a reader's text per module 기능 For each top-level module, reads it with the bundled reader and stores its Overview and Key Concepts with the reader's name.
  • /abbd-setup stance 기능 Fixes that setup never asks the human: the first committed state is the baseline. It needs no pstack.
